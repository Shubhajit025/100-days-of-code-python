# Musical Time Machine - Create your own playlist

A simple musical time machine that takes a date from you and then scrap data from `Billboard` website with the date given, and then it stores the data set inside a list. Then using YTMusic we make a playlist for those scrapped songs.

## Features :
- Scrap data from `Billboard` based on your given date with year and month.
- Create a playlist with `YTMusic` in your ytmusic profile.

## Tech Used :
- Python
- BeautifulSoup (bs4)
- ytmusicapi --> `YTMusic`
